# PDP Governance

Helps delivery teams keep stakeholders informed during a project. It produces clear status
reports by pulling from the project plan and live Jira progress, and feeds the same information
into the overall project governance scorecard.

**Version:** 1.0.0 · **Author:** Kaizen Analytix LLC

This plugin covers keeping stakeholders informed and maintaining governance throughout the
Kaizen PDP — turning plan and sprint data into periodic status communication that also keeps the
cross-phase governance scorecard current.

## Skills

| Skill | Description |
|---|---|
| [status-report](skills/status-report/README.md) | Drafts the weekly or periodic Status Report (D16, Mandatory) from the project plan and Jira progress, renders a branded `.pptx` to `2. Plan`, and feeds the governance scorecard (D37). |
