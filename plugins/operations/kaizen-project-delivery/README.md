# PDP Delivery

Helps delivery teams run the **build phase** of a Kaizen PDP engagement. It generates sprint and
monthly review summaries straight from Jira, giving the team a consistent, shareable record of
progress to review with stakeholders.

Version: 1.0.0

## Skills

| Skill | Description |
|---|---|
| [sprint-review](skills/sprint-review/README.md) | Generates a Sprint Review (T32) or Monthly Kaizen Project Review (T33) deck from Jira sprint data and saves the `.pptx` to `5. Develop`. |

## Where it fits

This plugin covers the build/delivery phase of the Kaizen PDP — the recurring sprint and monthly
review cadence that keeps the team's progress recorded and reviewable while the solution is being
developed.
